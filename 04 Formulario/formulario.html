Todos los formularios en la web, manejan metodos para el envio de las dieferentes peticiones que realiza el usuario. Considerando la arquitectura cliente servidor, el manejo de las peticiones se hace por medio del protocolo http y acutalmente por https, cada peticion debe de ser atenddia en un tiempo de respuesta conforme al modelo TCP/IP. Los metodos principales de los formularios son:

    • GET:

      Este metodo se encarga de enviar la informacion del formulario por medio de la salida estandar(conocida como url), del navegador, esto propicia que puedan existir inyecciones de codigo realizando violaciones a la seguridad del sistema

      POST:

      Este metodo se encarga de enviar la informacion para poder registrar un cambio o un nuevo registro dentro del sistema guiandola igual por el metodo estandar pero mediante un ocultamiento,esto significa que no es visible para el usuario. Lo que nos ofrece un mayor grado de seguridad en el manejo de la informacion


    • En resumen los metodos son:

    • Get:Sirve para enviar y realizar operaciones de lectura o consulta
      Sirve para enviar informacion de un recurso al servidor con el fin de registrarlo
      Delete: Sirve para eliminar un recurso especifico dentro del servidor, obteniendo una respuesta de actualizacion
      Put: Sirve para almacenar informacion de un recurso particular y conectarse al servicio para realizar la actualizacion
      Head: Sirve para regresar el codigo de respuesta de cualquer cabecera HTTP asociada a un recurso
